1 登录与注册

首次使用需要管理员创建账号，然后登录系统

截图：登录页
截图：首页（登录后）

首次登录

  1. 打开小程序，进入登录页面
  2. 输入管理员提供的用户名和密码
  3. 点击「登录」按钮
  4. 登录成功后自动跳转到首页仪表盘
💡 提示：登录页面支持「记住密码」功能，勾选后下次打开自动填充。已登录用户再次进入会直接跳转首页。

管理员创建用户

  1. 进入「我的」→「人员管理」（仅 root 管理员可见）
  2. 点击添加按钮，输入新用户的用户名、密码、姓名
  3. 选择角色：root（管理员，拥有全部权限）或 普通用户（业务操作权限）
  4. 保存后，新用户即可使用该账号登录

修改密码

  1. 进入「我的」→「修改密码」
  2. 输入旧密码、新密码、确认新密码
  3. 点击保存，密码修改后自动更新登录令牌

3 商品库管理

管理所有可销售的商品，包含分类、售价和库存

截图：商品库列表
截图：添加商品

添加商品

  1. 点击底部「商品库」Tab → 右下角 + 浮动按钮
  2. 填写商品信息：
    • 商品名称：必填
    • 分类：硬件 / 软件（决定税率）
    • 单位：台、个、套等
    • 含税售价：实际卖给客户的价格（含税）
    • 成本价：进货成本
    • 库存数量：当前库存
  3. 点击保存
💡 税率说明：硬件类商品税率 13%（除以 1.13），软件类商品税率 6%（除以 1.06）。系统在计算毛利时自动应用对应税率。含税售价 ÷ 税率 = 不含税收入，毛利 = 不含税收入 − 成本。

编辑 / 删除商品

  • 仅 管理员（root）可以编辑和删除商品
  • 在商品列表中点击编辑按钮进入编辑页
  • 普通用户可以添加商品，但看不到编辑/删除按钮

搜索与缓存

  • 顶部搜索框支持按商品名称搜索
  • 列表数据有本地缓存，切换页面秒开，后台静默更新
  • 下拉刷新可手动获取最新数据

5 借货流程

借货 → 销售 → 归还，完整业务流程

截图：借货列表
截图：添加借货
截图：借货详情

整体流程

📦 添加借货 → 🏪 销售商品 → ↩️ 归还未售商品

添加借货

  1. 进入「借货」Tab → 点击右下角 + 按钮
  2. 选择客户（或点击"+ 新增客户"添加）
  3. 选择商品（可添加多个商品，点击"+ 新增商品"添加）
  4. 每行商品可修改数量和售价（默认取商品库售价）
  5. 选择借货日期，可填写备注
  6. 点击「确认借货」提交
⚠️ 注意：借货数量不能超过当前库存。借出后库存会相应减少。

借货列表（双Tab）

  • 借货详情 Tab：按客户显示你的所有借货记录，支持搜索客户名或商品名
  • 我的库存 Tab：显示你当前手上的库存（已借出未还 + 未售出的），只显示数量 > 0 的商品
  • 支持排序：数量多→少，最近借货新→旧

归还商品

  1. 在借货列表点击进入某条借货的详情页
  2. 详情页支持两种视图：按时间或按商品查看
  3. 单个归还：点击每条记录旁的「归还」按钮，输入归还数量
  4. 批量归还：点击右上角「批量归还」→ 勾选要归还的商品 → 确认归还
  5. 归还会触发云函数事务：库存 +1，借货状态更新为 returned
    6. ✅ 事务保障：归还操作使用数据库事务，确保库存恢复和状态更新同时成功或同时失败，杜绝数据不一致。

借货状态说明

状态含义
🟡 pending借出中，尚未归还
🟢 returned已全部归还
🔵 sold已销售（通过开票自动标记）
🟠 transferring调货中，等待对方收货

6 销售开票

开具销售单，自动计算毛利和税额

截图：销售列表
截图：添加销售

开票流程

  1. 进入「销售」Tab → 点击右下角 + 按钮
  2. 选择客户
  3. 选择商品（可从商品库选择，或自动带入你的借货商品）
  4. 填写每行商品的数量和含税售价
  5. 选择付款状态：未付款 / 已付款（默认未付款，避免误操作）
  6. 底部「本单预览」实时显示：
    • 📘 开票金额（含税总额）= 数量 × 含税售价（蓝色高亮显示）
    • 📊 销售金额（不含税收入）= 含税价 ÷ 税率
    • 💰 毛利 = 不含税收入 − 成本
  7. 确认无误后提交

税额计算规则

硬件：不含税收入 = 含税售价 ÷ 1.13
软件：不含税收入 = 含税售价 ÷ 1.06
毛利 = 不含税收入 − 成本价
开票金额 = 数量 × 含税售价
💡 开票金额 vs 销售金额：开票金额是你开给客户发票上的实际金额（含税），销售金额是财务意义上的不含税收入。系统同时记录两者。

销售列表筛选

  • 状态标签栏：未付款 / 已结清 / 已红冲 / 全部，带数量统计
  • 搜索框：按客户名实时搜索
  • 月份选择器：切换不同月份
  • 排序：时间升降、金额升降
  • 顶部汇总栏显示：本月合计（销售金额 + 开票金额）
  • 每条记录底部显示开票金额（蓝色）

7 红冲作废

开错票了？红冲功能帮你安全作废并恢复数据

截图：红冲操作

使用场景

开票后发现商品类目、价格或数量有误，需要作废原单重新开票时使用。

红冲规则

  • ❌ 已结清单不可红冲（已收款确认的单据受保护）
  • ❌ 已红冲单不可重复操作
  • ✅ 所有人可以红冲自己名下的销售单

操作步骤

  1. 进入「销售」列表，找到要作废的销售单
  2. 点击该单右侧的「红冲」按钮
  3. 确认弹窗中点击确认
  4. 系统自动执行（事务保护）：
    • 标记该销售单为"已红冲"
    • 恢复对应商品的库存
    • 恢复对应的借货状态（sold → pending）
  5. 手动重新开正确的销售单
✅ 事务保护：红冲操作在一个数据库事务中完成，标记红冲、恢复库存、恢复借货状态要么全部成功，要么全部回滚。
⚠️ 注意：红冲后的销售单会在列表中显示红色「已红冲」标签，所有报表和汇总统计会自动排除已红冲单。

8 调货功能

同事之间互相调拨货物

截图：发起调货

调货流程

📤 发起方选择商品 → 👤 选择接收人 → 📨 发送调货请求 → 📥 接收方确认收货

发起调货

  1. 进入借货详情页，点击「调货」按钮
  2. 选择要调出的商品和数量（每项可独立设置）
  3. 选择接收员工
  4. 确认发送，系统创建调货请求，原借货标记为 transferring

接收调货

  1. 进入调货列表页（借货 Tab 内入口，或首页预警栏）
  2. 双 Tab 布局：待处理 / 处理记录
  3. 在待处理列表中找到待接收的调货
  4. 点击确认收货
  5. 系统事务处理：
    • 发方原借货扣减（全量→标记 returned，部分→数量扣减）
    • 发方库存减少
    • 接方创建新的 pending 借货记录
    • 接方库存增加
💡 首页会显示待处理调货数量，方便及时处理。

常见疑问

常见问题 FAQ

使用中可能遇到的问题，这里都有答案

借货和销售有什么区别？

借货是你从库存中取出商品带在身上去销售的过程。借货后库存减少，但还没有产生销售收入。
销售是实际开票给客户，记录销售收入和毛利。销售开票时会自动关联你借出的商品，标记为"已销售"状态。
简单理解：先借货 → 再开票销售 → 未售出的归还。

红冲是什么？什么时候需要红冲？

红冲是财务术语，指作废一张已开的销售单。当你在销售开票后发现商品选错了、价格填错了、数量不对等情况，就可以用红冲功能作废原单。红冲后，库存和借货状态会自动恢复，你可以重新开正确的票。
注意：已确认收款的已结清单不可红冲。

硬件和软件的税额是怎么算的？

硬件类商品适用 13% 增值税率，不含税收入 = 含税售价 ÷ 1.13。
软件类商品适用 6% 增值税率，不含税收入 = 含税售价 ÷ 1.06。
毛利 = 不含税收入 − 成本价。
系统在开票时自动根据商品分类选择正确的税率计算。

忘记密码怎么办？

请联系管理员（root 账号）重置密码。管理员在「人员管理」中可以重置任何用户的密码。出于安全考虑，系统不提供自助找回密码功能。

调货和借货有什么关系？

调货是指你把手上的借货商品转给另一位同事。比如 A 借了 10 台设备，B 那边正好有客户需要，A 可以通过调货功能把其中 3 台转给 B。调货后 A 的库存减少、B 的库存增加，B 收到后可以直接销售或归还。

首页显示的数据是所有人的还是我自己的？

首页显示的今日销售额、库存总数、未收款项、借货数量都是你个人的数据，不会看到其他同事的信息。管理员可以在报表页面查看全局数据。

可以在电脑上使用吗？

可以！微信小程序支持在电脑版微信中直接打开使用。不过头像显示等少部分功能在电脑模拟器中可能受限（真机正常）。建议在手机上使用以获得完整体验。

数据安全吗？会不会丢失？

所有数据存储在微信云数据库中，由腾讯云提供底层存储保障，数据可靠性极高。关键操作（归还、红冲、调货确认）均使用数据库事务保护，保证数据一致性。建议定期使用「数据导出」功能做本地备份。
